# BrainGram

BrainGram — прототип современного мессенджера с графитовым интерфейсом и фиолетовыми акцентами.

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
cp .env.example .env
npm run dev
```

В файле `.env` укажи URL проекта Supabase и публичный anon/publishable key. Секретный `service_role` key нельзя помещать во frontend или GitHub Pages.

## Настройка Supabase

1. В Supabase открой **SQL Editor** и выполни `supabase/schema.sql` — он создаёт таблицу профилей, политики доступа и триггер регистрации.
2. Затем выполни `supabase/migrations/20261118_profile_avatars.sql` — миграция добавляет `avatar_url`, публичное чтение изображений аватаров и загрузку только в папку текущего пользователя.
3. Для GitHub Pages добавь в **Settings → Secrets and variables → Actions** секреты `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.

Аватары доступны по публичной ссылке, поэтому не загружай туда приватные фотографии или документы. Пользователь может загружать, заменять и удалять файлы только в собственной папке.

## Что уже работает

- Адаптивный интерфейс для компьютера и телефона
- Регистрация и вход по электронной почте через Supabase
- Уникальный username и профиль пользователя в Supabase
- Загрузка квадратного аватара с уменьшением до 512×512
- Сохранение URL аватара в профиле и загрузка его при следующем входе
- Список серверов и каналов, переключение между ними
- Локальный интерфейс отправки сообщений

## Что пока остаётся локальным прототипом

Сообщения, серверы, каналы, друзья и уведомления пока хранятся в состоянии браузера и не синхронизируются между устройствами. Для настоящего обмена сообщениями следующим этапом нужно добавить таблицы диалогов и сообщений, политики доступа и realtime-подписки Supabase.
