# BrainGram

BrainGram — прототип современного мессенджера с графитовым интерфейсом и фиолетовыми акцентами.

## Запуск локально

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно http://localhost:5173).

## Что уже есть

- Адаптивный интерфейс для компьютера и телефона
- Список диалогов и поиск по ним
- Переключение между чатами
- Отправка сообщений в локальном состоянии браузера
- Заготовка для дальнейшего подключения регистрации, базы данных и реального обмена сообщениями

> Сейчас это фронтенд-прототип: сообщения не сохраняются на сервере и не синхронизируются между устройствами. Для полноценного мессенджера следующим этапом подключим Supabase.
